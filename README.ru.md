# Island UI

**Ваш остров — как на ладони.**

![Island UI в игре: HUD, лист персонажа, список жителей, крафт и настройки](O1.webp)

**Продуманный и цельный интерфейс для Mad Island.** Он держится на нескольких принципах, и каждая из его [200 функций →](FEATURES.md) вырастает из них:

- **[Построен с нуля.](SHOWCASE.md#built-from-the-ground-up)** Не тысяча заплаток. Island UI делает шаг назад и полностью перерабатывает интерфейс, от идеи до кода.
- **[Само собой.](SHOWCASE.md#second-nature)** Всё показано так, как люди естественно воспринимают вещи, поэтому ничего не нужно объяснять. Предметы подлетают к вам, когда вы их подбираете, а характеристики показывают, что они значат, а не просто голые числа.
- **[Игра, а не бумажная работа.](SHOWCASE.md#play-not-paperwork)** Рутина уходит с дороги. Топор появляется в руке, когда вы бьёте по дереву, вы пьёте у колодца без единого клика, а одно нажатие выгружает все сундуки вокруг в ваши сумки.
- **[Одна задача.](SHOWCASE.md#one-job)** Island UI — большой проект с узкой целью: интерфейс. Он намеренно не выходит за свои рамки, чтобы не мешать контенту игры и другим вашим модам. Его удобства остаются в духе игры, а правки, меняющие правила, живут в Island Ex.

Этот проект сделан с любовью, и я хочу, чтобы он был по-настоящему хорошим. Мне очень интересно ваше мнение, так что напишите мне в [Discord](https://discord.com/users/1523362502224777439) или [откройте issue здесь](../../issues).

## Установка

Скачайте `Island-UI-vX.Y.Z-installer.zip` со страницы [Releases](../../releases), распакуйте куда угодно и дважды щёлкните `install.bat`. Он находит игру через Steam, добавляет BepInEx, только если его ещё нет, и копирует мод. `uninstall.bat` удаляет его обратно.

<details><summary><b>Другие загрузки и удаление вручную</b></summary>

| Загрузка | Для кого |
|---|---|
| `Island-UI-vX.Y.Z-installer.zip` | **Проще всего.** Установщик, описанный выше. Не трогает другие моды и настройки и ничего не скачивает. |
| `Island-UI-vX.Y.Z-with-Island-Ex-installer.zip` | Тот же установщик, вместе с Island Ex. |
| `Island-UI-vX.Y.Z-with-BepInEx.zip` | Без установщика: распакуйте в папку игры (рядом с `Mad Island.exe`). BepInEx 5.4.23.5 в комплекте. |
| `Island-UI-vX.Y.Z.zip` | У вас уже есть BepInEx 5: распакуйте в папку игры. |
| `Island-Ex-vX.Y.Z.zip` | Только Island Ex: распакуйте в папку игры. Нужен BepInEx 5. |

Папка игры обычно `C:\Program Files (x86)\Steam\steamapps\common\Mad Island` (в Steam: правый щелчок по игре, *Управление*, *Просмотреть локальные файлы*). Windows может предупредить о запуске скачанного скрипта; установщик — это обычный текст, его можно посмотреть в [`installer/`](installer).

Чтобы удалить вручную, удалите `BepInEx/plugins/IslandUI` и `BepInEx/plugins/islandui-art` (и `BepInEx/plugins/IslandEx` для Island Ex).

</details>

## Настройки

В меню игры под *Option* есть пункт **Island UI**. Изменения применяются сразу. Мод следует языку игры или тому, который выберете вы: английский, упрощённый китайский, японский, русский, бразильский португальский, испанский или немецкий.

<details><summary><b>Страницы, переводы и файл конфигурации</b></summary>

Страницы разбиты на группы: Общие (указатель и язык), Цель, Бой, Уведомления, Окна, Сюжет и Горячие клавиши. Если установлен **Island Ex**, у него появляется свой пункт.

<img src="SET.jpg" width="480" alt="Окно настроек на странице «Бой»">

Переводы сделаны машинным переводом, поэтому исправления приветствуются: откройте issue или отредактируйте `BepInEx/plugins/IslandUI/Localization/<language>/strings.txt` (а также `item-guide.tsv`, `story-choices.tsv`) и пришлите. В начале каждого файла написано, как это сделать.

Отключить крупные части (окно окрестностей, панель действий, панель цели, список жителей, листы персонажей) можно в `BepInEx/config/madisland.islandui.cfg`.

Значки модов в левом нижнем углу титульного экрана показывают, что они загрузились; наведите на значок, чтобы увидеть версию, щёлкните, чтобы выключить или включить мод.

</details>

## Island Ex

<img src="island-ex.png" width="64" align="right" alt="Island Ex">

Island UI играет по правилам игры: он меняет то, как вы видите игру и как до чего-то добираетесь, но никогда не меняет того, что вы можете делать. Изменения правил живут в отдельном небольшом моде, Island Ex, в том же релизе. Island UI он не нужен.

<details><summary><b>Что делает Island Ex</b></summary>

- **Фильтр эффектов**: выключите любой визуальный эффект, который не хотите видеть.
- **Удержание для сопротивления**: в захвате удержание кнопки атаки продолжает бить.
- **Остаётся на экране**: игра больше не сворачивается при Alt+Tab или щелчке на другом мониторе.
- **Сухо в доме**: дождь больше не идёт внутри дома.
- **Отдаление камеры**: камеру можно отвести дальше, чем позволяет игра.
- **Сломанные инструменты остаются**: изношенный инструмент остаётся в сумке, сломанный, для ремонтного набора.

</details>

## Ограничения

Island UI ещё молод. 0.9 переделывает большую часть интерфейса; в него играли, но долго не тестировали: ждите шероховатостей и случайных ошибок. Некоторые собственные экраны игры ещё не перестроены и выглядят и работают как раньше. Если что-то сломалось, больше всего поможет issue с приложенным `BepInEx/LogOutput.log`.

Проверено на ветке Steam `beta_open`, сборка 25095856, с BepInEx 5.4.23.5. После обновления игры найдите в `BepInEx/LogOutput.log` строку `Patch census [IslandUI]: ... all bound.` Если там написано что-то другое, обновление что-то сдвинуло, и моду нужен новый релиз.

## Исходный код

Каждый коммит здесь — один релиз; теги версий совпадают с архивами релизов.

<details><summary><b>Как собрать</b></summary>

Для сборки нужны .NET SDK и установленная игра (проекты ссылаются на её DLL):

```
dotnet build src/IslandUI/IslandUI.csproj -c Release
dotnet build src/IslandEx/IslandEx.csproj -c Release
```

Сборка копирует DLL в `BepInEx/plugins` игры; добавьте `-p:GameDir="D:\...\Mad Island"`, если игра в другом месте, или `-p:NoDeploy=true`, чтобы собрать без копирования. Island UI также нужны `art/*.png` в `BepInEx/plugins/islandui-art`.

</details>
